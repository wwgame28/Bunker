# Формат контентных пакетов

Пакеты — UTF-8 JSON-объекты. Имя файла без `.json` — идентификатор пакета. `_meta` содержит описание; остальные ключи — массивы категорий. У записей стабильный `id` и уникальный в категории `text`. Не изменяйте ID опубликованной записи, если на неё уже ссылаются партии. Не удаляйте используемые пакеты до завершения партий.

Обычная карточка:

```json
{"id":"my_skill_001","text":"Чтение речных лоций","tags":["navigation"]}
```

Поля персонажа ссылаются на категории `professions`, `health`, `hobbies`, `baggage`, `skills`, `biographies`, `personalities`, `fears`, `secrets`, `achievements`, `morality`. Пол и возраст создаёт движок. `relations`, `goals`, `specials`, `bunkers`, `catastrophes`, `events` имеют дополнительные поля.

Теги: `medical`, `engineering`, `radio`, `chinese`, `water`, `food`, `rescue`, `navigation`, `negotiation`, `security`, `science`, `craft`, `winter`. Тег здоровья в основном пакете отсутствует: диагноз не является автоматическим игровым преимуществом или штрафом.

Ресурсы: `water`, `food`, `power`, `medicine`, `morale`, `structure`. Шкалы ограничены 0–100.

Сцена:

```json
{
  "id": "extra_event_001",
  "text": "В эфире появился незнакомый позывной",
  "tags": [],
  "needs": ["radio"],
  "resource": "morale",
  "clue": "Повтор позволяет отличить сигнал от случайной помехи.",
  "options": [
    {"text":"Проверить сигнал","check":true,"effects":{"morale":8},
     "failure":{"power":-9},"success":"Связь установлена.","fail":"Батарея потрачена без результата."},
    {"text":"Записать сигнал до утра","check":false,"effects":{"morale":-3},
     "success":"Запись сохранена, окно связи упущено."}
  ]
}
```

Первый вариант — проверка, второй — консервативное действие. У `check=true` обязательно поле `failure` и тексты `success`, `fail`. `needs` — любой из подходящих тегов, не обязательная комбинация всех. Один игрок засчитывается один раз.

Катастрофа: `stages` — четыре текста, `pressure` — ресурс финального давления. Название катастрофы заранее группе не показывается; стадии раскрываются в актах 1, 2, 5, 7.

Характеристика укрытия: `effects` — стартовые прибавки. Особое условие: `effects`, `min_act` (в этой версии поддерживается начало в акте 3; ядро ограничивает использование актами 3–9). Оно одноразовое. Новые механики условий требуют расширения обработчика домена и тестов; JSON не исполняет код.

Отношение: `mutual=true` означает обратную запись второй стороне; `false` — только владелец знает этот факт.

Цель: `kind` из `together`, `apart`, названий ресурсов, `medical`, `ending`; `threshold` для ресурсов; текст может содержать `{target}` и `{threshold}`. Движок подставляет конкретного другого игрока. Для нового вида цели надо реализовать предикат в `finish()` и добавить тест.

Новый пакет можно создать с одной категорией или несколькими; основной пакет заполняет остальные. Администратор включает пакет кнопкой — изменения действуют для новых комнат. Валидация проверяет минимальное количество, уникальность ID/текстов, теги, эффекты и обязательную структуру. Запускайте:

```bash
python scripts/validate_content.py
python -m pytest -q
```

В начатую комнату выбранные карточки, текущая сцена, катастрофа и особенности копируются целиком. Будущие сцены берутся из зафиксированного списка имён пакетов, поэтому редактирование файлов во время активной игры способно повлиять на ещё не выбранные сцены. Для строгого воспроизведения сохраняйте старую версию пакетов вместе с резервной копией БД.
