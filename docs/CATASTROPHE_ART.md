# Иллюстрации катастроф

Стиль: «Амурский винтаж» — шелкография, гравюрная штриховка, старая бумага, угольный чёрный, лесная зелень, ржавый оранжевый и янтарный свет.

Каждой из 30 катастроф соответствует отдельный JPEG в `bunker/assets/catastrophes/<id>.jpg`. Иллюстрации показывают само бедствие; причины и последствия по-прежнему раскрываются через четыре сюжетных стадии. Это художественные вымышленные сцены, а не документальные изображения Благовещенска.

При переходе из лобби в первый акт бот сохраняет в очереди название, первую стадию и ID иллюстрации. В группе появляется фото с подписью, затем обычная панель. Для комнаты без группы фото получают доступные участники в ЛС. Повторный callback не создаёт второе стартовое сообщение. Перезапуск не теряет очередь; сетевые ошибки повторяются по прежним правилам доставки. Отсутствующий файл даёт текстовое сообщение.

Изображения входят в Docker через `COPY bunker ./bunker`. Не требуется API генерации, отдельный хостинг картинок или новый секрет. Новую катастрофу добавляйте в контент и кладите соответствующий JPEG; тест проверяет полноту набора.
