# Запуск «Бункер: Благовещенск» на Amvera

Источник: https://github.com/wwgame28/Bunker — ветка `main`.

1. Создайте приложение на Amvera, выберите Docker и подключите репозиторий `wwgame28/Bunker`. Если интеграция GitHub недоступна, загрузите содержимое проекта вручную, чтобы Dockerfile находился в корне Code.
2. Используйте файл `amvera.yml` из репозитория. Он собирает Dockerfile и монтирует постоянное хранилище в `/data`. Compose на Amvera не используется.
3. В разделе «Переменные» создайте **секрет** `BOT_TOKEN` и вставьте ваш токен BotFather. Сам токен в GitHub отсутствует.
4. Создайте обычную переменную `DATABASE_PATH` со значением `/data/bunker.sqlite3`.
5. Необязательно: `ADMIN_IDS` — ваш числовой Telegram ID, несколько ID разделяются запятыми; `LOG_LEVEL=INFO`. После запуска ваш ID покажет команда `/id` в ЛС бота. Добавление или изменение переменных требует перезапуска.
6. Запустите сборку и один экземпляр приложения. Домен и HTTPS боту для long polling не нужны.
7. Убедитесь, что в логах есть `Bot started: @...`. Откройте бота в Telegram, нажмите Start и создайте комнату.
8. Добавьте бота в группу по кнопке, пригласите минимум четырёх игроков. Каждый открывает личное приглашение и нажимает Start. Организатор запускает партию из личной панели.

## Если запуск остановился

- `Укажите BOT_TOKEN`: секрет не создан, назван иначе или приложение не перезапущено.
- `Unauthorized` / `TokenValidationError`: проверьте токен без пробелов и переносов строк.
- `Conflict`: остановите другую работающую копию того же бота.
- `Permission denied` для `/data`: проверьте подключение постоянного хранилища. Если платформа принудительно запускает контейнер не от root, каталог должен быть доступен этому uid. При обычном запуске entrypoint сам подготавливает права и затем запускает бота без root.
- Бот не отправляет персонажа: игрок должен первым нажать Start в личном чате и не блокировать бота.
- После пересборки пропали комнаты: DATABASE_PATH должен указывать в `/data`, не в `/app` или относительный `data`.

## Обновления

После новых коммитов в main запустите пересборку/обновление на Amvera. Автоматическое получение новых коммитов зависит от подключённой интеграции Amvera с GitHub; в самом проекте нет доступа к аккаунту Amvera и его секретам. Никогда не удаляйте постоянное хранилище при обновлении.

Документация платформы: https://docs.amvera.ru/applications/configuration/docker.html и https://docs.amvera.ru/applications/configuration/variables.html .
